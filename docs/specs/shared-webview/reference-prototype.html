Référence des composants existants

Extraits de Communauté, Remise en seed et Upload. Aucun nouvel écran d’application.

Les styles de chaque source sont conservés, y compris leurs différences. Les interactions utilisent uniquement des données fictives.

Provenance et périmètre

CSS complet copié depuis le panneau existant. Fragments HTML simplifiés à partir de view.js, valeurs fictives substituées. L’encadrement de cette référence et ses libellés ne font pas partie du produit.

Les panneaux bureau et Web utilisent ces mêmes fichiers. Cette référence ne simule pas les sélecteurs natifs, les services, les actions du tracker ou le shell. Les pages approuvées restent inchangées.
