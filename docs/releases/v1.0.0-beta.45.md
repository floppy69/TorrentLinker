# TorrentLinker 1.0.0-beta.45

## Media

- The player shows the playing film's details under the picture: poster, year, runtime, rating, file flags and description. On desktop and web.
- **Horizon**, inspired by Kodi's Aeon Nox, replaces Collection. Its three views, **Home**, **Showcase** and **Wall**, are chosen in Settings or in Media's **Options**. The selected poster grows, and Horizon has its own player: a slim bar during playback, the film's details on pause. A layout saved as Collection opens Horizon's Wall.

## Settings

- Settings is now a page of the main window instead of a separate window, which could stay white on Wayland. It opens at the first click, even during background work. Leaving it applies what you saved; coming back to Media from Settings restores Media Center.
- A bundled page that stays blank now logs why in `torrentlinker.log`.

## Installation

- Windows, Linux AppImage, macOS Apple Silicon, browser companion and Docker distributions are provided by this release.
- Restart an existing desktop or server installation after updating. For Docker, use `ghcr.io/vietnoirien/torrentlinker:1.0.0-beta.45`, or update the `beta` tag.

This is a beta release.
