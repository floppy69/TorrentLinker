# TorrentLinker 1.0.0-beta.46

## Playback

- Desktop video no longer stutters every few seconds: the player saves its position off the interface thread, and the media database no longer waits on the disk for each save.

## Media

- Media has no page header any more. Its menu holds the **Target client** selector, left of the Media Center button.
- **Cinematic home:** the selected title stays at the top while the rows scroll beneath it and is a little lower. The wheel over a row scrolls that row sideways, and one wheel-up over the title brings the menu back.
- **Horizon Home** fills one screen. The category's title is its menu, and the row loads the whole category as the selection moves along it. The wheel moves the selection, and the chosen poster lifts in a soft light, with its neighbours in a wave. **See all** opens the Wall's compact grid.
- **Horizon Showcase** fits one screen, and the wheel moves its carousel's selection.
- Grids load more titles as you scroll, without a **Load more** button. The title panel's **Assistant** button is gone: ✦ in the menu opens the same chat.

## Search and keyring

- The **Category** menu lists only the sub-categories of the chosen pill, and is hidden under *All*. Turning on adult content shows XXX without reloading.
- A dismissed keyring unlock prompt is no longer shown again on every read.

## Installation

- Windows, Linux AppImage, macOS Apple Silicon, browser companion and Docker distributions are provided by this release.
- Restart an existing desktop or server installation after updating. For Docker, use `ghcr.io/vietnoirien/torrentlinker:1.0.0-beta.46`, or update the `beta` tag.

This is a beta release.
