# TorrentLinker 1.0.0-beta.41

Cette version corrige les changements demandés mais omis de la bêta.39. La candidate bêta.40 a été arrêtée avant publication pour intégrer la correction du logo.

## Zen et Plans

- Jusqu’à 4 Go, le poids vaut désormais taille ÷ 4 Go, avec un minimum de 0,0001. Merci à n3woz pour la contribution dans la PR #73.
- Au-delà de 4 Go, la courbe reste une estimation ajustée aux exemples publiés de 25 et 60 Go. La formule exacte n’est pas publiée.
- Les nouveaux paramètres utilisent Note par défaut. Les choix déjà enregistrés sont conservés.
- Note privilégie la meilleure note initiale individuelle, sans bonus de durée ni pondération par la taille. À note égale, les téléchargements plus petits passent en premier. Desktop, Web UI et Plans répartis appliquent la même règle.

## Remise en partage et interface

- Le logo TL apparaît dans la navigation de l’application et du Web UI. L’identité Linux et le lanceur associent la fenêtre à TorrentLinker dans le dock.
- Le dossier de liens est désormais un réglage par client, accessible dans les paramètres sur desktop et Web UI. Le tableau de remise en seed garde seulement un statut compact et un raccourci.

- La confirmation de renommage affiche tous les chemins dans un tableau défilant adapté à l’écran. Les raccourcis Oui/Yes et Non/No suivent la langue; Entrée et Échap refusent par défaut.
- Les noms accentués composés et décomposés qui désignent déjà le même fichier ne provoquent plus un renommage inutile lors de la remise en partage.
- Les grandes bibliothèques partagent les instantanés du client torrent. Les lectures de listes de fichiers ralentissent lorsque le client répond lentement et restent annulables.
- Les champs numériques conservent le focus et le défilement; la molette ne modifie plus leurs valeurs. Les réglages tiennent dans l’espace disponible et Windows reçoit une identité explicite pour la barre des tâches.
- La commande `diagnose-storage` mesure un petit échantillon en lecture seule. La vitesse soutenue du disque USB de Woodiny reste à vérifier sur sa machine.

## Communauté

- Commentaires, votes de confiance et messages dans les canaux général/de classe, avec file persistante, horaires, limites quotidiennes et modèles modifiables sur desktop et Web UI.
- 200 suggestions françaises modifiables. Les envois sont désactivés par défaut et passent par le compagnon 0.6.0 fourni avec cette version.
- Un envoi incertain n’est jamais répété automatiquement. Les XP restent indiqués comme non confirmés; aucun gain n’est garanti. Les uploads sont exclus de cette fonction.

Cette version reste une bêta. La version stable reste 0.12.2.

## English

This release restores requested changes omitted from beta.39. The beta.40 candidate was stopped before publication to include the logo correction.

- Zen size weights are linear up to 4 GB with a 0.0001 minimum. Thanks to n3woz for PR #73. Above 4 GB, the curve remains an estimate fitted to the published 25 GB and 60 GB examples.
- New settings default to Note; saved choices remain unchanged. Single-client and distributed Plans prioritize individual initial scores, with smaller downloads breaking ties.
- The TL logo appears in desktop and Web UI navigation. Linux desktop identity and launcher matching associate the window with TorrentLinker in the dock.
- The link folder is saved per client in Settings on desktop and Web UI. The reseed board keeps a compact status and a settings shortcut.
- Rename confirmation fits the screen and supports localized Yes/No shortcuts. Unicode filename aliases that already identify the same file avoid unnecessary renames.
- Large-client scans share snapshots and pace file-list reads. Windows numeric inputs preserve focus/scroll, settings fit the available screen, and taskbar identity is explicit. The read-only storage diagnostic samples a small amount of data; the reported USB-drive freeze still needs confirmation on the affected machine.
- Desktop and WebUI Community controls provide scheduled comments, owner-chosen votes and general/class chat, editable templates, daily caps and 200 French suggestions. Install companion 0.6.0. Sending defaults off; uncertain sends are not automatically repeated and XP awards are unconfirmed. Uploads remain outside this feature.

This is a prerelease. Stable remains 0.12.2.
