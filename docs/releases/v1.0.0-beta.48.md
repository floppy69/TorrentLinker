# TorrentLinker 1.0.0-beta.48

## Cross-seed

- **Indexers** (Settings): add Torznab Indexers by hand, or import them from Prowlarr or Jackett. c411 stays built in. Each Indexer's rate limits are obeyed.
- **Automatic Cross-seed.** Torrents in your client and Library Items are searched on the other Indexers. A Full Match, or a Partial Match of at least 95 %, is added stopped, verified at 100 % by the client, then started. Missing files are never downloaded.
- **Cross-seed tab** in Library → Reseed: review what waits for you, retry failures, remove a Cross-seed whose data disappeared. Notifications report the results.

## Members (opt-in on the server)

- Off by default. Set `TL_WEB_MEMBERS=on` on the server to enable accounts, invitations, Viewers with PINs, Shared Screens, Requests and Wishes, Age Ratings, a Member Assistant with daily caps, and Notifications (SMTP and push).

## Search and Media

- XXX search comes through your c411 session via the browser companion, and through Torznab otherwise. **Update the companion extension** for it. The first read can take about 30 seconds.
- Pre-rolls and Studio: play clips before a film, and make new ones from tracks with keyframes.
- Media tracker rows say why they are empty.

## Settings and clients

- Saved secrets show as `••••••••` with an eye to reveal them. The extra c411 API keys are edited one by one.
- Client addresses without `http://` are accepted, and a wrong one names the field.
- After a refused login, TorrentLinker stops logging in until you change the settings or press Test. This protects against qBittorrent's IP ban, which now has its own message.

## App achievements

- Settings → Join the community now shows achievements for verified reseeds, playlists, completed Studio renders, tested RSS rules and community imports. Current seeding has its own badge; it does not count as a TorrentLinker reseed.
- Progress stays in a private local ledger. Retained history is credited only when there is enough evidence, and duplicate records cannot inflate progress. Explicitly paired installations of the same account can merge their ledgers over encrypted connections.
- Sharing is off by default. Future achievements and already-earned achievements have separate sharing choices. The Community Site receives badge codes, not torrent identities, filenames or media history. Collections remain member-only.
- Desktop and Web UI include pairing removal, reviewed ledger backup/restore, and a corrected account link. Site controls let members manage consent and badge visibility.

## Interface

- Toasts and busy buttons everywhere; known server errors appear in your language.
- A new header bar. On a phone, ☰ opens the same sidebar as on a computer, over the dimmed page. Activité uses plain words.
- Media uses the approved theatre layout on desktop and Web: a full-width player with bottom controls, followed by the large selected-film banner. The banner stays pinned while rows scroll. Its menu remains visible and only hides over the theatre player, without shifting the banner. Selecting a poster keeps the current playback. Play starts the selected title. The larger poster accompanies the full synopsis, with language, genre, version and file-size tags and actions at the bottom of the banner. Media Center uses the whole width and remains active after leaving player fullscreen.
- The banner keeps the same height when changing films. Missing covers use a transparent TL logo in the reserved poster space. Long synopses scroll inside their own area. The watched eye turns green, and row arrows sit beside a small See all link when needed.
- Media’s compact topbar groups extra tools under Options. The two-colour TorrentLinker wordmark is shared by sign-in and the desktop/Web sidebar; it moves to the media topbar in enlarged view.
- Assistant and ReleaseScore group Share and Browse under a Community menu. Flux has Community rules.

## Compatible playback

- Desktop and Web share the frosted settings menu for quality, speed, audio, subtitles, repeat and queue controls. Playback buttons use plain icons; the timeline shows actual buffered ranges.
- FFmpeg can stream H.264/AAC at 360p, 480p, 720p or 1080p while keeping the source intact. Quality changes preserve film position, pause state and playback speed. Original and external playback remain available.
- Conversion is opt-in, runs on the app/server host and writes no converted movie to disk. The Web host limits concurrent encoders to two and cancels them on stop/disconnect. Desktop uses a private loopback stream.

## Security

- The web server no longer logs Torznab URLs with their API key.
- The Owner stays signed in across a server restart (sign-ins are kept as digests in the config folder; a new startup password ends them).
- The web app no longer offers GitHub crash reports; a failure shows its message only.
- Behind an HTTPS reverse proxy (`TL_SECURE_COOKIE=1`), the companion extension downloaded from the server now allows the server's HTTPS address; before, it could not connect.

## Installation

- Windows, Linux AppImage, macOS Apple Silicon, browser companion and Docker distributions are provided by this release.
- Restart an existing desktop or server installation after updating. For Docker, use `ghcr.io/vietnoirien/torrentlinker:1.0.0-beta.48`, or update the `beta` tag.

Beta.48 will remain in testing for one week. If no blocking issues are reported, the next release will be **1.0.0-rc.1**. Members are opt-in on the server.
