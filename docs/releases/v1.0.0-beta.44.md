# TorrentLinker 1.0.0-beta.44

## Shared desktop and web interface

- Search, the download queue, Library inspectors, Upload preparation, RSS, Torrents, Assistant, Media browsing, Zen, Settings and Documentation now share their interface across desktop and web. Desktop video playback remains native.
- Seeding uses filters and paged torrent rows for large collections. Plan has collapsible controls, client destination cards, minimum torrent and seeder counts, and explanations behind its information button.
- Settings keeps section spacing consistent and exposes connection, folder, path and profile configuration in the shared workspace.
- RSS keyboard navigation and Upload draft actions remain accessible on smaller screens. Background job labels follow the selected language.

## Media and responsiveness

- Downloading qBittorrent videos expose **Preview downloaded portion** directly on cards and title views. Other clients do not advertise unsupported preview functionality. Preview still requires a single-file sequential download and verified pieces; web previews extend through **Refresh preview**.
- Downloads detected after the library scan retain their unfinished status, so preview does not disappear behind a generic unavailable state.
- The Profile poll waits while desktop video plays. Community planning stops searching for additional comment slots once the week is full, reducing playback stalls.
- The first Media rescan runs quietly and refreshes the view only when the library changes.
- Continue-watching cards have a small remove cross that clears the resume position without deleting the file.

## Search, clients and transfers

- ReleaseScore adds compact score pills, editable profiles and an equipment questionnaire in Search settings. Colour describes profile fit separately from the score. Unknown season-pack duration remains unknown; advanced Poussée scoring is not included.
- Reviewed transfers between clients and verified SFTP seedbox transfers are available. Remote file access settings are shared with Transfers.
- c411 torrent audits and reviewed tracker updates are available in the shared Torrents workflow.
- Reseed layouts are configured per client. Clients unable to rename inside a torrent use persistent Link Folders to preserve original paths.

## Guides and installation

- Refreshed setup and workflow guides include ten new screenshots, clearer configuration examples and a client feature matrix. The guides are bundled for offline reading.
- Windows, Linux AppImage, macOS Apple Silicon, browser companion and Docker distributions are provided by this release. Companion remains version 0.6.0.
- Restart an existing desktop or server installation after updating. For Docker, use `ghcr.io/vietnoirien/torrentlinker:1.0.0-beta.44`, or update the `beta` tag.

This is a beta release. Codec availability still depends on the platform or browser; TorrentLinker does not transcode video. The interface audit and outstanding platform codec measurements remain tracked separately.
