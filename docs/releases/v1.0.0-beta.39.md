# TorrentLinker 1.0.0-beta.39

Cette bêta ajoute un espace de remise en partage dans la Bibliothèque, sur desktop
et dans la Web UI. Il prépare les noms attendus par les torrents avec des liens
symboliques, sans renommer les fichiers de votre bibliothèque.

## Remise en partage

- Un tableau suit chaque fichier, de la recherche de correspondances à sa remise
  en partage, avec une colonne pour les éléments à revoir.
- Lancez les étapes séparément ou enchaînez-les avec « Tout lancer ». Les cartes et
  la progression indiquent l'étape en cours. Vous pouvez suspendre, reprendre ou
  arrêter le traitement.
- Choisissez un dossier de liens distinct des dossiers de la Bibliothèque. Les
  liens conservent les noms attendus par le torrent et restent en place pendant le
  partage. Les fichiers d'origine gardent leurs noms et leur emplacement.
- Le contenu passe une vérification locale, puis celle du client torrent avant le
  démarrage du partage. Les correspondances ambiguës ou incomplètes demandent une
  intervention.
- Les correspondances de chemins permettent au client torrent de retrouver les
  liens et leurs cibles, y compris lorsqu'il tourne dans Docker.
- La Web UI retrouve le traitement en cours après un rechargement de la page.

## Corrections

- qBittorrent vérifie les fichiers à remettre en partage dans leur dossier de
  destination, même lorsqu'un dossier de téléchargements incomplets est configuré.
  Merci à DisasteR pour la correction dans la PR #68.
- Une tâche déjà en attente dans la Web UI ne s'ajoute plus une seconde fois.
- La Web UI conserve la page ouverte après un rechargement et permet la navigation
  explicite avant la configuration du client.

## Validation et limites

Les dix contrôles CI de la PR #69 passent, dont les parcours navigateur et les
tests avec qBittorrent, Deluge, Transmission et rTorrent. La suite locale compte
2 119 tests réussis et 158 tests ignorés.

Le nouveau parcours avec liens a aussi été testé avec qBittorrent sous Linux et
Docker, avec des chemins accentués et des correspondances de chemins. Ce parcours
n'a pas encore été testé sur macOS ou Windows. La création de liens doit être
autorisée sur le système. Une vérification déjà lancée dans le client peut se
terminer pendant une pause. Conservez le dossier de liens tant que les torrents
associés restent dans le client.

Cette version reste une bêta. La version stable reste 0.12.2.

## English

This beta adds a Reseed workspace under Library on desktop and in the Web UI.
It creates symbolic links with the names expected by each torrent, preserving
your original filenames and locations.

- Follow each item on a board from matching through verification to seeding.
  Items that need attention have their own column.
- Run individual steps or use Run all to process them in order. Moving cards and
  progress feedback show the current operation. Pause, resume and stop are available.
- Choose a separate Link Folder outside your Library Folders. Links remain in
  place while the torrents are seeding.
- Local content verification and the torrent client's own check must pass before
  seeding starts. Ambiguous or incomplete matches stop for review.
- Path Mappings support clients with different filesystem paths, including Docker.
- Reloading the Web UI reconnects to the running job.
- qBittorrent now checks a Reseed in its destination folder even when an incomplete
  downloads folder is configured. Thanks to DisasteR for PR #68.
- Duplicate queued Web UI jobs are prevented. Navigation survives page reloads,
  and explicit navigation works before client setup.

All ten PR CI checks passed, including browser acceptance and real torrent-client
tests. The local suite passed 2,119 tests with 158 skipped. The new symlink workflow
was also tested with qBittorrent on Linux and Docker, accented paths and Path
Mappings. That workflow has not yet been tested on macOS or Windows, and the
system must allow symlink creation. An in-flight client check may finish while
paused. Keep the Link Folder while its torrents remain in the client.

This is a prerelease. The stable release remains 0.12.2.
